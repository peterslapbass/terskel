Los XLSX del RETC pesan ~60 MB cada uno y **no** se publican en el repo: se descargan del portal del MMA con la URL de arriba y se verifica el sha256. Los parquet derivados sí están en el repo, con las fuentes citadas en cada ficha.

## Cómo se verifica

```bash
python src/ingest/retc.py --years 2023 2024 2025
```

La ingesta compara el sha256 del archivo descargado con el del manifest y falla si no coincide.
